Tech Explorer — เวอร์ชันแยกไฟล์

โครงสร้าง:
- index.html : โครงสร้างหน้าเว็บ/เนื้อหา
- css/style.css : CSS ทั้งหมดที่เดิมอยู่ใน <style>
- js/app.js : JavaScript ทั้งหมดที่เดิมอยู่ใน <script>
- assets/ : สำหรับไฟล์รูปภาพ/สื่อประกอบ

หมายเหตุ: HTML เดิมอ้างถึงไฟล์รูปภาพภายนอก/ไฟล์ในโฟลเดอร์เดียวกัน เช่น bg.jpg.jpg, รูปที่1.png–รูปที่4.png และ ผู้จัด.png แต่ไฟล์เหล่านี้ไม่ได้ติดมากับไฟล์ HTML ที่อัปโหลด จึงยังคงชื่อ path เดิมไว้เพื่อไม่เปลี่ยนเนื้อหา/การอ้างอิงของเว็บ
